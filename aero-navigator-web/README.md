# Aero-Navigator Web

Local development steps:

1. Open terminal in `e:/Aero Website/aero-navigator-web`
2. Install dependencies:

```bash
npm install
```

3. Start server:

```bash
npm start
```

4. Open http://localhost:3000 in your browser.

Notes:
- The app stores data in `aero_navigator.db` (SQLite) next to `server.js`.
- To create test accounts, use the Sign Up form in the UI.
